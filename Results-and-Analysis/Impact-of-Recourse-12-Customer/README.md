# Impact of Recourse — 12-Customer Instances

This repository contains supplementary files supporting the computational analysis presented in the paper. The Excel workbook reports results for the **12-customer instances** and evaluates the impact of recourse under different disruption scenarios.

## Excel Workbook

**File:** `EJORMinor(12-custImpactofRecourse).xlsx`

The workbook contains three worksheets:

### `12-custexactplots`

Contains the results and plots for the **exact method**, comparing:

- Recourse
- No recourse

across the considered disruption scenarios.

### `Agatz12custplots`

Contains the results and plots for the **heuristic method**, comparing:

- Recourse
- No recourse

across the considered disruption scenarios.

### `ImpactofRecourseAnalysisfv`

Contains the **no-disruption results (initial solutions)** and the percentage comparisons for the **12-customer exact-method results**.

The following comparisons are reported:

- **Recourse vs. No Recourse**
- **Recourse vs. No Disruption**
- **No Recourse vs. No Disruption**

These comparisons quantify the effect of disruption and the impact of allowing recourse relative to both the disrupted no-recourse case and the initial no-disruption solution.

## Supplementary Files

Additional Excel files and Python scripts in this repository provide supporting computational results and analysis associated with the paper.
